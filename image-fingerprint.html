    What each code is
    
    
      
  • Code — the whole photo squeezed to 16 characters, like a4f3c91e07b2d856. The same file always gives the same code; change one pixel and it changes completely.
    • 
      
  • Fingerprint — 16 characters too, but based on what the photo looks like. A resized or re-saved copy keeps nearly the same fingerprint, which is how the compare below works.
    • 
      
  • Hex, Binary, Decimal, Octal — every byte of the file written out in that base.
    • 
      
  • Base64, Base85, Base32 — the whole file as text, the way an email attachment or a data URL carries it.
    • 
      
  • To find a photo on the internet, use Google Lens or TinEye — they compute a fingerprint like this against billions of images.
