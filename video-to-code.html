What each one is
  • Story — the run-down: each shot with its start time, how long it lasts, how bright and colourful it is, how much movement there is, and its main colours.
  • Profile — the whole video at a glance: length, size, shot count, pace, overall brightness and colour.
  • Shots — one fingerprint per shot, so you can match a clip against another copy of it.
  • Frames — the fingerprint of every sampled frame, with how much changed since the previous one.
  • Code — the file squeezed to 16 characters (the first 4 MB of it, for a big video). Re-encode the video and it changes completely; the fingerprints above survive that.
  • Colours — the colours that fill the most screen time across the whole video.
  • ASCII — the keyframe of each shot drawn in text.
  • Hex and Base64 — the file's bytes. Video files are big, so these read the first 4 MB only.
