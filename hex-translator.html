What each format is
HexEach byte as two digits, 0–9 and a–f. Hi → 48 69
BinaryEach byte as eight 1s and 0s. Hi → 01001000 01101001
DecimalEach byte as a plain number, 0–255. Hi → 72 105
OctalBase 8, the old Unix way. Hi → 110 151
Base64The compact form used for email attachments and data URLs. Hi → SGk=
Base85Shorter than Base64, with a bigger set of characters. Hi → NW0
Base32A–Z and 2–7 only, so it survives being read aloud or typed by hand. Hi → JBUQ====
MorseDots and dashes. Letters, digits and basic punctuation only. Hi → .... ..
NATOThe phonetic alphabet used on radio. Hi → Hotel India
ROT13Each letter jumps 13 places. Running it twice undoes it. Hi → Uv
URLPercent encoding for web addresses. a b → a%20b
HTMLEntities for web pages. café & → caf&#233; &amp;
LeetLetter swaps, not a real encoding: o→0, l/i→1, s→5, t→7, g→6, e→3, a→4, b→8, z→2
Hexspeak: words you can spell in hex

Hex only has 0–9 and a–f, so words get spelled with digits standing in for letters.

0oc0c0a → cocoa
1l or ic1a55 → class
5s5ace → sace
6g60dde55 → goddess
7t7a57e → taste

Letters with no stand-in — h, k, m, n, p, q, r, u, v, w, x, y — can't be written in real hex at all. The Leet format above is looser and keeps them as they are.
