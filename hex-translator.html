Hexspeak: words you can spell in hex

Hex only has 0–9 and a–f, so words get spelled with digits standing in for letters. These are the common swaps.

0oc0c0a → cocoa
1l or ic1a55 → class
5s5ace → sace
6g60dde55 → goddess
7t7a57e → taste
2z2e5t → zest
8b (loosely)8ad → bad

Letters with no stand-in — h, k, m, n, p, q, r, u, v, w, x, y — can't be written in real hex at all.

How the conversion works

Each character is turned into bytes using UTF-8, then each byte is written as two hex digits. Plain English characters take one byte each, so A is 41. Accented letters and emoji take more: é is C3 A9 and 🔥 is F0 9F 94 A5.

Going the other way, the hex box ignores spaces, dashes, colons, line breaks and 0x prefixes, so you can paste hex in almost any format. It needs an even number of digits, since every byte is two.
